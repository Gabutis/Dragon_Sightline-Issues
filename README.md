# Dragon Sightline — Issues

Čia galite pranešti apie **Dragon Sightline** programėlės klaidas, pateikti pasiūlymus ir atsiliepimus.

## Pranešti apie problemą

Atidarykite **Issues → New issue** ir pasirinkite:

- **Klaidos pranešimas** — jei kažkas neveikia arba veikia neteisingai.
- **Pasiūlymas** — jei turite funkcijos ar patobulinimo idėją.

### Ką įtraukti į klaidos pranešimą

Kad problemą būtų lengviau pakartoti ir ištaisyti, nurodykite:

- programėlės versiją;
- naudojamą įrenginį;
- kas tiksliai nutiko;
- kokius veiksmus atlikote prieš atsirandant klaidai;
- kokio rezultato tikėjotės;
- jei įmanoma, pridėkite ekrano nuotrauką arba klaidos tekstą.

### Ką įtraukti į pasiūlymą

Trumpai aprašykite:

- kokios funkcijos ar pakeitimo norėtumėte;
- kaip tai turėtų veikti;
- kuo tai būtų naudinga.

**Prieš kuriant naują įrašą verta patikrinti, ar tokia problema ar pasiūlymas jau nėra užregistruoti.**

---

## English

Use **Issues → New issue** to report a bug or suggest an improvement.

For bug reports, include the app version, device, what happened, steps to reproduce it, expected result, and screenshots or error text if available.

For suggestions, briefly explain what you would like changed, how it should work, and why it would be useful.

**Before creating a new issue, please check whether the same bug or suggestion has already been reported.**
